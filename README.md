# AlgoView

AlgoView is a web application for interactively visualizing fundamental computer science algorithms.  
Built with **Next.js**, **TypeScript**, and **TailwindCSS**, it provides a clean and responsive interface to explore and understand key algorithmic concepts.

## Features

- 🔢 **Sorting algorithms** – Visualizations for Bubble Sort, Quick Sort, Merge Sort, and more.
- 🔍 **Searching algorithms** – Includes Binary Search and Linear Search.
- 🌳 **Tree structures** – Interactive views for BST, AVL, and Trie.
- ▶️ **Interactive animations** – Step-by-step visualizations with basic playback controls.
- 📘 **Educational content** – Each algorithm includes:
  - A brief description
  - Execution steps
  - Pseudocode
  - Time and space complexity

## Tech Stack

- [Next.js](https://nextjs.org/) – React framework with server-side rendering and optimizations
- [TypeScript](https://www.typescriptlang.org/) – Typed JavaScript for better developer experience
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework
- [Framer Motion](https://www.framer.com/motion/) – For smooth and interactive animations

## Next.js Features Used

- `next/link` for client-side routing
- `next/image` for optimized image loading
- `next/font` for custom font integration
